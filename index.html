Quick Revision

Student Tag Cheat Sheet

Keep these essential HTML5 tags handy during lab exercises and exams.

<ul> & <li>

Unordered bulleted list where item sequence does not change meaning.

<ol> & <li>

Ordered numbered/lettered list. Supports type, start, and reversed.

<dl>, <dt>, <dd>

Description list pairing terms (<dt>) with definitions (<dd>).

<thead>, <tbody>, <tfoot>

Semantic row groups separating table headers, body rows, and summary footers.

<tr>, <th>, <td>

Table row (<tr>), bold header cell (<th>), and standard data cell (<td>).

colspan & rowspan

Attributes on <th> or <td> to merge cells horizontally or vertically.
